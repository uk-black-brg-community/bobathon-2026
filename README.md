## What is Bobathon?

Bobathon is the IBM UK Black BRG's annual hands-on AI event, held during Black History Month.

In 2026, participants used **IBM Bob** — IBM's AI coding assistant — to build something meaningful in a single session. No prior coding experience was needed.

Build themes included:
- 🏛️ Champions Wall
- 🤝 Needs Assessment
- 🍽️ Cultural Cookbook (Diaspora Bites)
- 🌱 Mentorship Manifesto
- 🎓 Scholarship Finder
- 📢 BRG Comms Studio
- 🌍 Know Your Roots

## Project Submissions

This repository is the **community showcase** for Bobathon 2026 projects.

Participants keep their code in their own GitHub repositories. This repo holds a catalogue of project entries — links, descriptions, and what was built.

> **Your code stays yours.** Submitting here does not transfer ownership of your project. You retain all rights.

### How to submit your project — easy route

1. Go to the [Issues tab](../../issues/new?template=submit-project.yml) and click **Submit a Bobathon Project**
2. Fill in the form — project name, description, link to your work, how you used Bob
3. Click **Submit new issue**

That's it. No Git knowledge needed. You'll need a free [GitHub account](https://github.com/signup).

### How to submit — developer route (fork & PR)

If you're comfortable with Git: fork this repo, copy `submissions/_template.md` to `submissions/your-project-name.md`, fill it in, and open a pull request. Full instructions: [CONTRIBUTING.md](CONTRIBUTING.md)

## About the IBM UK Black BRG

The IBM UK Black Business Resource Group (Black BRG) is a community of IBMers committed to creating an equitable and inclusive workplace. Bobathon is our annual Black History Month signature event — bringing together IBMers and external guests to learn, build, and celebrate.

This GitHub organisation is a community initiative run by BRG members. It is not an official IBM product or service.
