Bobathon 2026

On 21 October 2026, IBMers and external guests came together at 20 York Road, London to build with IBM Bob — IBM's AI coding assistant — in a single session. No prior coding experience needed.

This page is the community showcase. If you built something on the night, submit it below and your project will appear in the gallery.

How to submit your project

  1. You'll need a free GitHub account.
  2. Fork the bobathon-2026 repository.
  3. Copy submissions/_template.md to submissions/your-project-name.md.
  4. Fill in the fields — title, description, link to your repo, and how you used Bob.
  5. Open a pull request with the title Add submission: Your Project Name.

That's it. We'll review and merge it, and your project will be part of the record.
