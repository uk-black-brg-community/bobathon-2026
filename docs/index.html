Bobathon 2026

On 21 October 2026, 66 people came together at 20 York Road, London to build with IBM Bob — IBM's AI coding assistant — in a single session. Some built a working prototype in 15 minutes. No coding experience needed.

This page is the community showcase. If you built something on the night, share it below — it only takes a couple of minutes.

Share your project

  1. Click the button below — it opens a short form on GitHub.
  2. Fill in your project name, what you built, and how you used Bob.
  3. Click Submit new issue.

You'll need a free GitHub account — it takes about two minutes to create one.

Your code stays in your own repository. We only collect a short description and an optional link.
