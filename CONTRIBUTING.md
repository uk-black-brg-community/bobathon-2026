# How to Submit Your Bobathon 2026 Project

Thank you for taking part in Bobathon 2026! This guide walks you through submitting your project to the community showcase.

**Your code stays in your own repository.** We only collect a short metadata file with a link to your project — no source code upload required.

---

## Before you start

You will need:
- A free [GitHub account](https://github.com/signup)
- Your project repository URL (can be public or private — we only display the link you provide)

---

## Submission steps

### 1. Fork this repository

Click **Fork** at the top right of this page. This creates your own copy of the repo under your GitHub account.

### 2. Create your submission file

In your forked copy, navigate to the `submissions/` folder.

Copy the template file:

```
submissions/_template.md  →  submissions/your-project-name.md
```

Use a short, lowercase filename with hyphens instead of spaces, for example:
- `submissions/diaspora-cookbook.md`
- `submissions/mentorship-manifesto.md`
- `submissions/champions-wall.md`

### 3. Fill in the template

Open your new file and complete all the fields. The template has guidance comments to help you.

The fields are:
- **title** — the name of your project
- **author** — your name or your team name
- **organisation** — your company or institution (optional)
- **repo** — link to your project repository
- **demo** — link to a live demo or video (optional)
- **theme** — which Bobathon theme you built on
- **description** — a short paragraph (2–4 sentences) about what you built
- **built_with_bob** — one sentence on how you used IBM Bob

### 4. Open a pull request

Once your file is saved, open a pull request from your fork back to this repository.

Set the PR title to: `Add submission: [Your Project Name]`

For example: `Add submission: Diaspora Bites Cookbook`

The BRG team will review and merge your submission. We may ask for small edits if anything is missing.
